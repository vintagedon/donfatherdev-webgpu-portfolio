## 5. Conventions

Purpose: Staging is a workspace, not a permanent home. Files should move to their target directory once reviewed and approved. If a file has been in staging for an extended period, it is stalled work or belongs in `recycle/`.

Visibility: In private repos, this directory is tracked. In public repos, this directory is gitignored.

Structure: Files in staging can use any naming or organization that makes sense for the work in progress. Structure is imposed when files move to their final location.
